# moneyMoves

Prosty tracker finansów osobistych (przychody/wydatki) zbudowany w czystym
JavaScript, bez frameworków i bibliotek — projekt stworzony jako praktyczne
podsumowanie fundamentów JS: domknięcia (closures), manipulacja DOM,
delegacja zdarzeń, metody tablicowe (filter, reduce), operator spread
oraz localStorage.

## Funkcje

- Dodawanie przychodów (KP) i wydatków (KW) z walidacją danych
- Kategoryzacja wydatków (dynamicznie tworzone przez użytkownika)
- Filtrowanie historii transakcji (wszystkie / przychody / wydatki)
- Automatyczne obliczanie salda na bieżąco
- Trwałe zapisywanie danych w localStorage (dane przetrwają odświeżenie strony)
- Usuwanie transakcji

## Technologie

- HTML5
- CSS3 (Flexbox)
- Vanilla JavaScript (ES6+) — bez frameworków, bez bibliotek

## Uruchomienie

Otwórz plik `index.html` w przeglądarce — projekt nie wymaga instalacji
ani serwera.

## O projekcie

Ten projekt powstał jako praktyczne zastosowanie fundamentów JavaScript
po ukończeniu bloków nauki poświęconych: closures, DOM/eventom,
metodom tablicowym, mutacji/niemutowaniu danych oraz operatorom
spread/rest. Celem było zbudowanie działającego produktu wykorzystującego
wyłącznie te mechanizmy, bez sięgania po frameworki czy zewnętrzne API.
